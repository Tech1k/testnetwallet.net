Where it goes
  • The testnetwallet.net domain and hosting
  • The Monero testnet node and light-wallet server (coming with Monero support)
  • The faucet and pool that keep the testnet playground stocked
  • Time spent building and maintaining the tools
Other ways to help
  • Star or watch the project on GitHub
  • Report bugs or suggest features in the issues
  • Run your own copy (it's a static site, AGPL-3.0)
  • Tell other testnet developers about it

These tips don't buy testnet coins (those are free and worth nothing) and don't unlock anything. The wallet is free and always will be.
